How this is built

  • Each screen is a standalone file with its stylesheet inlined — open one directly, no server, no build, no JS.
  • To edit: change screens/NN.body.html (or the shared parts/base.css) and run parts/build.sh; it re-inlines the stylesheet into every screen.
  • Every length is a cell: 1ch horizontally, 18px vertically. A screen is exactly 150ch × 40 rows, so anything drawn here is expressible in OpenTUI.
