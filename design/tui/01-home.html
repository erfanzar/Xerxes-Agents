Decisions

  • The chips are the entry points, not decoration. Each one is a real command with a real number key, and each carries the state that makes it worth pressing — /diff shows +128 −42, /agents shows 2 need you. A chip that can't show live state doesn't earn a slot.
  • Resume is a chip, not a prompt. Reopening yesterday's work is the most likely first action, so it gets the ⏎ key, the blue rail, and the one sentence that says what you were doing — not just a session id.
  • Where am I / what's happening / what can I do is answered by three fixed bands: wordmark (which tool), chips (what's pending), statusbar (cwd, branch, dirty count, view keys, version). The statusbar is the only place F-keys are advertised, and it stays identical on every screen.
  • Amber appears exactly once — on ✱6, the uncommitted-file count. It is a warning, not brand colour, so it must not compete with the wordmark gradient.
  • The composer owns its own mode label. Interaction mode ("auto · accept edits") lives against the input it governs, not in the statusbar, because it changes what pressing ⏎ will do.
