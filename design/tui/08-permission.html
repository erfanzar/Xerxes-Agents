Decisions

  • Three statements, in this order: what runs, who asked, why you're being asked. Every approval prompt that people learn to reflex-approve is one that answered fewer than three. The third is the one usually missing — without it, "why is this even asking" has no answer and y becomes muscle memory.
  • The command is verbatim, in a code box, with real line breaks. No summary ("remove and reinstall dependencies"), no truncation, no reflow that could hide a second statement after a &&. If it is too long to show, it is too long to approve blind.
  • The tint comes from the policy verdict, not from vibes. Amber here is warn: recursive delete, a rule that fired and is named on screen. A command that matched nothing renders in the neutral blue frame — the colour is evidence, so it has to be traceable to a rule.
  • "Who asked" names the subagent and its depth. A fleet means the requester is usually not you and not the main session; approving without knowing which worktree is about to be modified is approving the wrong thing.
  • "Always" is scoped to this exact command shape and shows you the string it would store. Whitelisting the Bash tool from inside an rm -rf prompt is how permission systems quietly turn themselves off. A changed path or flag asks again.
  • Deny is the Esc default and the cheapest key. Two ways to say no (n with a reason the agent can act on, esc without), one way to say yes forever, and it costs an extra decision.
  • The statusbar shows the block — F6 agents (1 waiting) — so if you dismiss this card the stall stays visible instead of becoming a silently hung fleet.
